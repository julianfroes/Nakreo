# Arte de las cartas

Cada carta física del mazo tiene su propio arte (20 en total). Sube aquí las imágenes
con estos nombres exactos (WebP, 800 × 600 px, calidad ~80):

| Archivo                  | Carta                               |
| ------------------------ | ----------------------------------- |
| `<rol>-1.webp`           | 1.ª copia normal del rol            |
| `<rol>-2.webp`           | 2.ª copia normal                    |
| `<rol>-3.webp`           | 3.ª copia normal                    |
| `<rol>-especial.webp`    | carta especial del rol              |

`<rol>` es uno de: `rh`, `ceo`, `jefeArea`, `ingeniero`, `sindicalizado`.

Ejemplo: `ceo-1.webp`, `ceo-2.webp`, `ceo-3.webp`, `ceo-especial.webp`.

Si falta alguna imagen, la carta muestra el icono de siempre. No hace falta registrar
nada en el código: basta con dejar el archivo en esta carpeta.
